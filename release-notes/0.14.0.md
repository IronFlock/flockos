## New

- IronFlockOS can use PTP (Precision Time Protocol) on a machine network, set per device in `/etc/flockos/ptp.conf`: it takes its time from the network's PTP master, or with `role=server` it is the PTP master for devices such as cameras. Without that file nothing changes.
- PCs with Intel graphics get the graphics firmware, for the display's power saving and hardware video, and PCs with Intel Smart Sound get their audio firmware.

## Changed

- chrony now keeps the time instead of systemd-timesyncd. It uses the same internet time servers as before, also those the network hands out, and on boards without a clock battery it starts from the time of the last run.
