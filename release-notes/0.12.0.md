## New

- PCs with Secure Boot are ready for firmware updates that the PC's own firmware applies at restart: FlockOS now keeps the boot file those updates need where the update tool looks for it.
- Every release now publishes the source code of the open-source software in its images, next to the images.

## Changed

- The proof of how a release was built is now created apart from the build itself (SLSA Build Level 3).
