## New

- A device behind a proxy gets it from `proxy.conf` next to the `.flock` on the FLOCKOS partition, or from `/etc/flockos/proxy.conf` on the device: the agent, Docker and the apps use it, and `ntp=` names NTP servers where the network blocks NTP to the internet.
- Factory reset: a file `factory-reset.conf` on the FLOCKOS partition makes the device erase its data at the next start and start as new; `keep-network=yes` in it keeps the network settings. A reset that fails is tried three times in all. Then the device gives it up and starts with what it has, so that it still comes online, and the reset's record says what was left.
- A device takes network settings from its boot medium: a NetworkManager profile saved as `network/<name>.nmconnection` on the FLOCKOS partition becomes the device's own at the next start and is removed from the medium. This gives a device a fixed address or a Wi-Fi network other than its `.flock`'s from its first start. If an enrolled device does not reach IronFlock with the new settings within 15 minutes, it goes back to the ones it had.

## Fixed

- Apps keep their data (the app's `/data` and `/shared`) through OS updates. Until now every OS update started the apps with empty data; the update to this release does so one last time.
